# Olaf · Tool Command Center

Interaktive, mobiloptimierte Sites-Seite für Olafs persönliche Einordnung von
29 ChatGPT-Funktionen. Die Vorschau enthält Projekt-, Kategorie- und
Prioritätsfilter, Suche, Detailansichten, kopierbare Prompt-Vorlagen sowie den
empfohlenen siebenstufigen Workflow.

## Lokale Vorschau

```bash
npm install
npm run dev
```

## Qualitätsprüfung

```bash
npm run build
npm run lint
npm test
```

Die Veröffentlichung ist ein separater Schritt und erfolgt erst nach
ausdrücklicher Freigabe.
